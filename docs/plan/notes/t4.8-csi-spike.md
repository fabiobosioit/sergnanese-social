# T4.8 spike — CSI Live girone page (local file only)

Source: a page saved by the user (rendered DOM copied from the browser, 1.8 MB, "Girone A - 2016", Crema committee, season 2026/27). Read locally on 2026-11-22; no request to CSI. The file holds real club names and logo URLs, so it stays **outside the repo** (it is currently untracked in the repo root: move it). The committed fixture in `Tests/Fixtures/csi/` must be sanitised.

This is the page after the browser ran its scripts (`slick-initialized` carousel), which is what `document.documentElement.outerHTML` returns in the app. The parser must be written against this shape, not against the raw server HTML.

## Match rows

## Consequences for the plan

- Parser: dedupe by match code; date has a year; venue from the tooltip; placeholder shield means no logo.
- Contract: `FetchedFixture` needs no CSI-specific key; the match code can go in a new optional `sourceMatchCode` only if the sheet finds a use for it (not needed for the first version).
- Allowed hosts for logos (if URLSession is allowed): `static.centrosportivoitaliano.it` only. The shield host is never fetched.
- Sanitised fixture: replace club names and logo ids, keep the structure, keep the 5x repetition and one played, one unplayed and one placeholder-logo row.
